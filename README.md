# laliga2stats

Will analyze the past two seasons (2024-2025, 2025-2026), in the second division of spanish football using data from fox sports

example here: https://www.foxsports.com/soccer/laliga-2/team-stats?category=defensive&season=2025&groupId=129


* Note: I was originally going to use fotmob but ran into some troubles with that (wasnt allowed to scrape pages that called APIs so I am using fox sports as an alternative)
